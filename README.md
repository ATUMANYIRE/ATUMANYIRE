## Research and practical learning

KinyaAI's miniature three-seed CPU experiment used 409,600 training tokens. On its held-out Wikipedia comparison, bits per byte moved from **3.260** for the base model to a **2.115** adaptation mean. The character 7-gram baseline remained stronger at **1.954**. It is a completed small experiment; the report also identifies future evaluation opportunities.

I participated in **picoCTF** and **Cyberlympics** and continue studying cybersecurity through Linux, Kali Linux, isolated VirtualBox labs and network/service enumeration. I also contributed a **winning DEVx project** involving dataset cleaning and application development.
